Fast, Source-Traceable Q&A over Emergency Department Records with an LLM
LangChain-Based Medical RAG System

Side Project | Dec 2025 – Feb 2026
Project Overview

A retrieval-augmented generation (RAG) question-answering project built over emergency department records: the system finds answers inside the notes themselves and cites where each one came from. Controlled experiments picked the embedding model and parameters. From there: FAISS vector retrieval, then quantitative evaluation with RAGAS — every technical decision backed by data. The goal throughout: answers that are grounded and traceable.

Experiments and the Reasoning Behind Each Choice
①Dataset size experiment
Compared retrieval quality at 5K / 20K / 50K records. The jump from 5K to 20K improved things markedly, while 20K to 50K converged, so 50,000 records was chosen as the cost-performance balance point.
②Text length analysis (chunk size)
The distribution showed a mean length of only 167 characters and a maximum of 464, with 69.3% of texts falling between 100 and 200 characters — hence chunk_size=200, overlap=20.
③Embedding model comparison
Three models compared on a single, consistent cosine similarity scale:
Model Cosine similarity (50K) Index build time
MiniLM 0.6870 102 s
Text2Vec 0.6947 342 s
BAAI/bge-m3 ✓ 0.7005 1056 s

Chose BAAI/bge-m3 — the strongest performer on mixed Chinese-English clinical text.

Quantitative Evaluation with RAGAS

Evaluation set: 30 items (10 easy / 10 medium / 10 hard), with answers drawn directly from the source text so they can be verified.

Metric Score Interpretation
Faithfulness 0.82 82% of answers are grounded in retrieved context; hallucination is well controlled
Context Recall 0.89 89% of the relevant information was retrieved correctly
Answer Relevancy 0.44 On the low side: mixed Chinese-English terminology makes the judge's back-inferred question unstable

By difficulty: context recall is perfect (1.00) on easy and medium questions and drops to 0.67 on hard ones, which is what I'd expect.

Technical Highlights
Experiment-Driven Parameter Selection
Dataset size, embedding model and chunk size are each backed by experimental data, so every decision can be explained quantitatively.
Working Around a LangChain FAISS Cosine Bug
Found the known issue where DistanceStrategy.COSINE actually returns L2 distance (GitHub issues #428, #17333), and switched to computing it manually with sklearn to guarantee correctness.
Quantitative Evaluation with the RAGAS Framework
Built a three-difficulty evaluation set and used gpt-4.1-mini as the judge, producing faithfulness, context recall and answer relevancy scores.
