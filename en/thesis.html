Integrating Local and Global Clinical Concepts via Semantic Mapping with MetaMap for Translated Chinese Emergency Department Texts: Disposition Prediction

Mar 2024 – Aug 2025

Emergency department crowding is a persistent problem, and TTAS triage still leans heavily on a nurse's clinical judgment at the moment a patient arrives. This study combines structured data with unstructured clinical text to build a decision-support prediction model — adding the selected text features raised the model's AUC from 0.8058 to 0.8829 (+0.077, about a 9.6% relative improvement).

  • Cleaned and processed an in-hospital emergency dataset of 810,000+ records, framed as a binary admission / discharge task
  • Used MetaMap for medical concept extraction, mapping varied phrasings (abdominal pain / stomach pain / AP) onto a single standardized concept
  • Drew on the 900 symptom features from a Yale study to select 1,215 dimensions of clinically relevant features for ED prediction
  • Designed a three-way negation encoding scheme, using NegEx to detect whether a symptom was negated
  • Chose Random Forest for modeling, balancing non-linear relationships against interpretability
  • Compared different text sources and found nursing records carried the most predictive signal
Model Choice and Negation Encoding
Random Forest was chosen because the data had already been converted into structured features: it handles non-linear relationships and exposes feature importance, which makes the model easier to interpret. For negation — a note reading “fever present, denies cough” — I designed a three-way encoding, Fever = 1, Cough = -1, separating “mentioned” from “mentioned but negated,” two clinically very different things.
Feature Selection: Narrowing 36,130 Concepts Down to 1,215
MetaMap extracts an enormous number of concepts, and not all of them matter for ED prediction. So I mapped the 900 key features curated in the Yale literature into the same concept space and compared: anything present on both sides was kept outright, while concepts unique to my own data went through two further filters, semantic type and term frequency. That took the feature count from 36,130 down to the 1,215 actually used — evidence that free-text clinical notes carry signal the vital-sign numbers never capture.
